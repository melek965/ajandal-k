    Klasör Seç

    Abonelik Linki

    4
    Takvime Ekle
    macOS Takvim
    iPhone / iPad

    1. Mac'te Takvim uygulamasını aç
    2. Menü → Dosya → Yeni Takvim Aboneliği…
    3. Kopyaladığın webcal:// linkini yapıştır → Abone Ol
    4. Güncelleme sıklığını "Her 15 dakikada" seç

    1. iPhone/iPad'de Ayarlar → Takvim → Hesaplar → Diğer
    2. Abonelik Takvimi Ekle → webcal:// linkini yapıştır
    3. İleri → Abone Ol → Kaydet
    Güncelleme sıklığı iOS tarafından yönetilir (~15 dk).
